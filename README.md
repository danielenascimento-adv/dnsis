# DNsis

Sistema do escritório Daniele Nascimento (processos, prazos, conversas, leads, honorários e relatórios), instalável no computador e no celular.

Este repositório contém **somente o programa**. Nenhum dado de cliente fica aqui: os dados ficam exclusivamente na conta Dropbox da usuária (pasta Aplicativos), acessada após login com o Dropbox.

Baseado no ERMS, de Rafael de Mello Souza (github.com/rafaadvogado/erms).
